# DonorConnect 🩸

**Blood Donation Coordination and Donor Management System**

DonorConnect is a web-based project developed for the Web Technologies course at American International University-Bangladesh (AIUB), Fall 2026–2027.

The project provides a user-friendly interface for connecting blood donors, blood requesters, donation coordinators, and administrators.

## Features

### Blood Donor
- Donor registration and login
- View donor profile
- Manage donation availability
- View donation appointments

### Blood Requester
- Requester registration and login
- Submit blood requests
- Track request status
- Provide feedback

### Donation Coordinator
- Coordinator login and dashboard
- Search for available donors
- Review blood requests
- Schedule donation appointments

### Administrator
- Administrator login and dashboard
- Manage users
- Manage coordinators
- View reports

## How to Run

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if necessary.
4. Open `index.html` using Live Server.
5. Select a user role from the homepage.

No backend installation is required for the current frontend version.

## Project Status

This project currently implements frontend interfaces, client-side validation, navigation, and simulated workflows. It does not yet provide production authentication, persistent database storage, or real blood donation scheduling.
